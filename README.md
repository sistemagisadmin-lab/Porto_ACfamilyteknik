# Porto_ACfamilyteknik

Website Company Profile & Landing Page modern untuk layanan tata udara, service AC, dan sistem HVAC (*Air Conditioning & Cooling Systems*) yang dibangun menggunakan **Astro 5** dan **Tailwind CSS v4**.

## ✨ Fitur & Keunggulan
- ⚡ **Super Fast & Lightweight**: Dibangun dengan Astro Island Architecture & Static Site Generation (SSG).
- 🎨 **Modern Glassmorphism UI**: Desain estetis bertema dark mode dengan ambient glow dan tipografi *Plus Jakarta Sans*.
- 📱 **Fully Responsive**: Tampilan optimal di semua perangkat (Desktop, Tablet, Mobile).
- 🛠️ **Modular Components**:
  - **Navbar**: Sticky glassmorphic header dengan mobile menu drawer.
  - **Hero**: Highlight interaktif dengan live climate monitor dashboard preview.
  - **Services**: Kartu layanan HVAC (Cuci AC, Pasang Baru, Service Kompresor, VRV/VRF, Freon, Ducting).
  - **About & Advantages**: Informasi kredibilitas, teknisi bersertifikat, dan kompatibilitas brand ternama.
  - **Process**: Alur kerja transparan 4 langkah mudah.
  - **Testimonials**: Ulasan kepuasan pelanggan residensial & komersial.
  - **Contact & CTA**: Tombol integrasi langsung ke WhatsApp & hotline.
  - **Footer**: Navigasi lengkap, link layanan, dan jam operasional.

## 🚀 Menjalankan Project

### 1. Instalasi Dependensi
```bash
npm install
```

### 2. Mode Pengembangan (Development)
```bash
npm run dev
```
Akses di browser pada `http://localhost:4321`.

### 3. Build Produksi
```bash
npm run build
```
Hasil build siap deploy akan berada di direktori `dist/`.

## 📦 Tech Stack
- **Framework**: [Astro 5](https://astro.build)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) via `@tailwindcss/vite`
- **Typography**: Plus Jakarta Sans (Google Fonts)
- **Icons**: Optimized inline SVG Icons
